# Práctica 1 - Flujo Básico de git y github

# 1. ¿Qué es una Base De Datos Relacional?
Es una tipo informacion que ayuda a organizar la informacion en una tabla,con relacion entre ellas 
# 2. ¿Qué es una Tabla en el contexto Base De Datos Relacionales?
Es una structura fundamental que almacena datos relacionados sobre una entidad especifica
# 3. ¿Qué es una relación en el contexto de Base De Datos Relacionales?
Es un vinculo lgico entre una o mas tablas y sirve para conectar datos relacionados 
# 4. ¿Qué representa una columna en el contexto de Base De Datos Relacionales?
Es un tipo de dato especifico o caracterista de una entidad o tabla
# 5. ¿Qué representa un renglón en el contexto de Base De Datos Relacionales?
Es un registro unico, individual y extructurado
# 6. ¿Qué es un motor de base de datos relacional?
Es un software que se encarga de almacenar y recuperar datos organizados 
# 7. ¿Cuáles son los motores de bases de datos relacionales mas populares?
MySQL, PostgreSQL, Oracle Database, Microsoft SQL Server, MariaDB y SQLite
# 8. ¿Cuál es el motor de base datos ligero que no necesita un servidor?
SQLite ya que es un motoro que ya proporciona un  motor de base de datos SQL
# 9. ¿Qué significa SQL en el contexto de base datos relacionales?
Structured Query Language (Lenguaje de Consulta Estructurado)
# 10. ¿Cuáles son los elementos de un sistema de información basado en base de datos relacionales?
tablas (entidades), campos (atributos), registros (tuplas), relaciones, claves (primarias y foráneas), el gestor (RDBMS) y el lenguaje SQ
